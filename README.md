# SHE Master — 반도체 사업장 안전관리 통합 포털 (개인 포트폴리오)

**제작: 이성호** — 기획, 자료 조사·검증, 디자인, 개발을 직접 한 개인 포트폴리오입니다. 화면 위 안내줄이나 맨 아래의 이름을 누르면 약력이 열립니다.

SK하이닉스 SHE(안전) 직무를 가정해 만든 안전관리자 업무 포털입니다. **SK하이닉스 공식 시스템이 아니며**, 회사 정보는 공개자료(지속가능경영보고서 2024·2025·2026, 뉴스룸)와 정부 발표·법원 판결·언론 보도만 사용했습니다.

## 여는 방법
- 온라인: GitHub Pages로 공개합니다(서버 프로그램 없이 동작하는 정적 사이트, https 자동 적용).
- 내려받아 보기: `index.html`을 더블클릭해 브라우저(Chrome·Edge)로 열면 됩니다. 서버가 필요 없습니다.
- 앱 설치·오프라인 캐시·자체 점검(`#qa`)은 웹 서버로 열었을 때 동작합니다. 예: 이 폴더에서 `python -m http.server 8765` 실행 후 http://localhost:8765 접속.
- 글꼴(IBM Plex)은 인터넷 연결 시 적용되고, 오프라인이면 맑은 고딕으로 표시됩니다.
- 입력한 값(업무 보드, 위험성평가, 점검 기록, 재발방지 진행 상황, 검색 기록 등)은 해당 브라우저에만 저장됩니다. **업무 › 데이터 백업·복원**에서 JSON 파일로 백업하고 다른 PC·브라우저에서 되살릴 수 있습니다.

## 실무 기능 (1단계)
- **백업·복원** — 입력 데이터 전체를 JSON 파일로 내보내기/가져오기(미리보기 후 부분·전체 교체), 데이터 지우기, 업무판의 30일 백업 알림
- **인쇄·PDF** — 인쇄 미리보기 화면(A4)에서 인쇄하거나 ‘PDF로 저장’: 5분 안전카드(한·영 병기 가능), SOP 교육자료(서명란), TBM 기록지, 위험성평가표(가로), 사고조사 보고서, 사고 보고 판정·보고 기록지, 정부 점검 자가점검표, 도급인 의무 점검표, 유해화학물질 취급시설 자체 점검표, 법정 주기 기한 계획표(가로), 재발방지 보고서
- **캘린더 내보내기** — 법정 주기 31개의 다음 기한을 .ics 파일로(아웃룩·구글 캘린더, 기한 전 알림)
- **화학물질관리법·고압가스 안전관리법** — 법정 주기 8개 추가, 공정안전 페이지의 두 법 핵심 의무와 물질별 규제 한눈표(특정고압가스·PSM 규정량·즉시 신고 기준량), 예방안전의 화학사고 즉시 신고(15분)·가스사고 통보(속보·상보) 판정

## 판정·작성 도구 (2단계)
- **작업허가서 작성기** (`#ptw`) — 화기·일반위험 허가 + 보충 허가 6종(밀폐공간·정전·굴착·방사선·고소·중장비), 작업허가 전 점검 14항목, 유형별 안전조치(안전보건규칙 조문·KOSHA C-C-49 조항), 가스 측정 판정, 발급 → 작업 중 → 종료 기록, A4 허가서 인쇄. SOP 상세에서 바로 시작. 3단계에서 작업 중 모니터링(별지 양식3, 20문항)과 작업허가 절차 평가(별지 양식4, 42문항)·인쇄 추가
- **가스 안전 도구** (`#gas`) — 감지경보기 설정값 검토(KGS FU211·FU212, KOSHA C-C-87), 혼합가스 폭발성·폭발하한계(KOSHA P-179), 비상 이격거리(ERG 2024)
- **호흡보호구 선정** (`#ppe`) — 산소·IDLH·유해비 → 할당보호계수(OSHA), 국내 안전인증 정화통 종류·등급·표시색, 방진마스크 등급
- **교육 이수 관리** (`#training`) — 사람별 정기·채용 시·특별교육(최초 작업 전 4시간·3개월 내 16시간)과 화관법 유해화학물질 안전교육 부족분, 면제 옵션(제27조), 현황표 인쇄·CSV
- **수치 판정 추가 탭** — 전체환기 필요환기량(안전보건규칙 제430조), 작업환경측정·특수건강진단 주기 판정(시행규칙 제190·202조, 작업환경측정 고시) → 업무판 법정 주기에 반영

## 콘텐츠 심화 (3단계)
- **물질 DB 63종** — 반도체 가스·약액·금속·불활성가스 29종 추가. 물질마다 법정 관리 구분(작업환경측정 별표21·특수건강진단 별표22·관리대상 별표12·특별관리물질·허가대상 시행령 제88조)을 칩으로 표시하고, ILO ICSC 카드와 KOSHA MSDS 검색으로 연결. 구분별 필터, 국내 노출기준이 없는 물질은 판정 도구에서 제외
- **SOP 19종** — X선 분석장비·이온주입기 정비(원자력안전법), 크레인·호이스트, 충전전로 근접 전기작업(접근한계거리), 지게차, 비상샤워·세안설비 점검, 굴착 6종 추가. 단계마다 조문·KOSHA 조항 근거 표시
- **정부 재해조사보고서 사례 3건** — 2026.5.26 고용노동부가 공개한 보고서 중 새 SOP와 같은 작업 유형(몰드변압기 감전, 지게차 끼임 2건, 굴착기 끼임)
- **KOSHA GUIDE 현행화** — 인용 지침 41건을 2026.1.30 정비 결과와 대조해 현행 번호로 바꾸고(예: P-94-2021 → C-C-49-2026, P-166-2020 → C-C-87-2026), 번호를 누르면 공단 원문 PDF가 열림. 출처·검증 페이지에 대조표
- **한·미 규제 비교** (`#bench` 두 번째 탭) — PSM·밀폐공간·LOTO·화기작업·호흡보호구를 한국 조문과 OSHA 조항으로 나란히 비교

## 운영과 신뢰성 (4단계)
- **법령 변경 점검** (`#sources/lawcheck`) — 인용한 법령·고시·기술기준 26건의 ‘포털 기준’ 판(시행일·공포번호)과 시행 예정 개정, 국가법령정보센터 현행본 바로가기, 월간 점검 기록(31일 경과 시 업무판 알림)과 점검표 인쇄. 2026-09-25 첫 점검 결과를 반영: 산안법 시행규칙 제37조~제37조의4(위험성평가 시기·근로자 참여·공유·기록 3년, 2026.6.1), 위험성평가 과태료(2027.1.1/2028.1.1), 폭염작업 조치(안전보건규칙 2025.7.17), 외국인근로자 기초안전보건교육(2027.1.8), 원자력안전법 교육훈련 개편(2027.1.1), 고압가스 EUV 노광장비 특정설비(2026.6.11)·별표31(2027.7.1), KOSHA B-M-7 번호 오기 수정
- **오프라인 사용** — 웹 서버(https·localhost)로 열면 서비스 워커가 포털 파일을 기기에 저장해 인터넷 없이 열리고, 앱처럼 설치 가능(manifest·아이콘). 상태 확인·다시 받기는 `#data`
- **포털 자체 점검** (`#qa`) — 전 페이지·탭·인쇄 양식을 한/영 × 3개 사업장 × 1024·375·320px에서 자동 렌더링해 스크립트 오류, 빈 화면, 영문 화면의 한글, 가로 넘침, 깨진 링크, 없는 출처·KOSHA 번호, 데이터 참조 오류를 찾음. 검사용 화면은 별도 저장 공간을 써서 입력값을 건드리지 않음
- **공유** (`#data`) — 기능별로 골라 내보내기(인계용), 데이터 사전과 법정 보존기간, 여러 사람이 함께 쓰려면 필요한 사내 시스템 요건. 정적 사이트이므로 동시 편집·전자 결재는 없음
- **만든 사람 약력** — 안내줄·바닥글의 이름을 누르면 페이지 이동 없이 약력 창이 열림(학력·자격·어학·연구·경험, 본인 제공 자료 요약)

## 근거와 한계
- 법령은 국가법령정보센터 원문(2026-09-25 현행본 재확인, 판별 목록은 `#sources/lawcheck`)을 기준으로 했습니다. 산업안전보건법·시행령·시행규칙은 2026.8.1 시행본, 안전보건규칙은 2026.3.2 시행본(고용노동부령 제450호, 2025.12.1 제454호 반영), PSM 고시는 제2025-30호, 위험성평가 지침은 제2024-76호, 화학물질관리법·시행규칙은 2025.10.1 시행본, 화학사고 즉시 신고 규정은 예규 제4호(2025.11.11), 고압가스 안전관리법은 2026.3.10(법)·2026.6.9(시행령)·2026.6.11(시행규칙) 시행본입니다.
- 2·3단계 도구의 기준: KOSHA GUIDE C-C-49-2026(안전작업허가, 구 P-94-2021)·C-C-87-2026(가스누출감지경보기, 구 P-166-2020)·P-179-2022(혼합가스 폭발하한계)는 원문 PDF 전문을, KGS FU211·FU212(2026.6.12 승인)는 해당 조항을, 보호구 안전인증 고시(제2023-64호) 별표4·5와 작업환경측정 고시(제2020-44호)는 원문을 확인했습니다. 해외 값은 미국 OSHA 29 CFR 1910.134(할당보호계수), EPA AEGL-2, ERG 2024(캐나다 교통부 공개본), NIOSH 포켓가이드에서 가져왔습니다. AIHA ERPG 값은 공개 표가 없어 싣지 않았고, 내화학 장갑 재질표는 공식 출처가 없어 제외했습니다.
